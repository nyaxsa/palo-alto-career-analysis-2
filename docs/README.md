# Career Progression & Promotion Gap Analysis

A portfolio project analyzing a Palo Alto Networks-style HR extract (1,470
employees) to explain **why employees might disengage** — promotion gaps
and role stagnation — rather than just predicting who will quit. That
framing is the differentiator from a standard attrition-prediction project.

## Project structure

```
palo-alto-career-analysis/
├── data/
│   ├── _generate_data.py           # builds the synthetic HR extract (run once)
│   ├── Palo_Alto_Networks.csv      # input data (1,470 rows)
│   └── palo_alto_networks_scored.csv  # output, written by the notebook's last cell
├── docs/
│   └── README.md                   # this file
├── files/                          # scratch space for exported charts/screenshots
├── career_progression_analysis.ipynb
├── app.py                          # Streamlit dashboard
└── requirements.txt
```

## About the data

`Palo_Alto_Networks.csv` is **synthetic**, generated by `data/_generate_data.py`
to match the shape of the classic IBM HR Analytics Attrition dataset
(same columns: `YearsSinceLastPromotion`, `YearsInCurrentRole`, `Department`,
`JobRole`, `Attrition`, etc.), rebranded for this project. It's built with
realistic correlations — e.g. attrition probability rises with promotion-gap
ratio, overtime, and low satisfaction — so the EDA, clustering, and scoring
in the notebook produce meaningful, defensible output. If you get access to
a real dataset later, drop it in with the same column names and everything
downstream keeps working.

To regenerate the dataset (e.g. with a different random seed):
```bash
python data/_generate_data.py
```

## How to run

```bash
python -m venv venv
source venv/bin/activate          # on Windows: venv\Scripts\activate
pip install -r requirements.txt

# 1. Generate the input data (skip if data/Palo_Alto_Networks.csv already exists)
python data/_generate_data.py

# 2. Run the notebook end-to-end (Jupyter, or from the command line):
jupyter nbconvert --to notebook --execute career_progression_analysis.ipynb --output career_progression_analysis.ipynb

# 3. Launch the dashboard (reads data/palo_alto_networks_scored.csv)
streamlit run app.py
```

## Pipeline summary

1. **EDA** — attrition rate, tenure distributions, promotion-gap vs. attrition.
2. **Feature engineering** — four tenure ratios normalized by `YearsAtCompany`:
   `PromotionGapRatio`, `RoleStagnationIndex`, `TrainingIntensity`, `ManagerStability`.
3. **Clustering** — K-Means (k=4, chosen via elbow + silhouette), cross-checked
   against Ward hierarchical clustering with Adjusted Rand Index.
4. **Cluster labeling** — clusters named from their mean ratios: Fast-track
   performers, Early-career explorers, Stable long-term contributors,
   High-risk stagnation profiles.
5. **Promotion Gap Score** — a weighted composite (0.4 gap + 0.4 stagnation +
   0.1 inverse training + 0.1 manager stability), bucketed into Low/Medium/High
   by tercile.
6. **Retention Opportunity flag** — still employed, Medium/High gap score,
   job satisfaction ≥ 2 — i.e., people where a career conversation could
   still make a difference.
7. **Export** — `data/palo_alto_networks_scored.csv`, consumed by `app.py`.

## Dashboard

`app.py` is a Streamlit app with filters (department, career cluster, gap
score, attrition status) and:
- KPI row (filtered headcount, % high-risk, retention opportunities, attrition rate)
- Headcount by career cluster
- Promotion gap score distribution
- Promotion gap vs. role stagnation scatter, colored by cluster
- Retention opportunities by department
- A sortable table of retention-opportunity employees
